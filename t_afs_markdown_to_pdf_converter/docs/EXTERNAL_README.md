# AFS Markdown to PDF Converter

Convert Markdown-formatted text into professionally styled PDF documents with the AFS purple theme.

## Features

- **Professional Styling**: Automatic AFS purple theme with branded footer logo
- **Easy Integration**: Base64-encoded PDF output works seamlessly with Swimlane workflows
- **Flexible Input**: Accepts any Markdown-formatted text up to 1MB
- **No Configuration**: Self-contained with no external dependencies or credentials required

## Use Cases

- Generate PDF reports from GenAI-created security summaries
- Convert case documentation to shareable PDF format
- Create formatted incident reports with consistent branding
- Transform Markdown notes into professional documents

## Quick Start

1. Add the connector to your Swimlane instance
2. Use the "Process Report Response" action in your workflow
3. Provide Markdown text as input
4. Receive base64-encoded PDF as output
5. Save or distribute the PDF as needed

Perfect for security operations teams who need to quickly generate professional documentation from automated or manual workflows.
