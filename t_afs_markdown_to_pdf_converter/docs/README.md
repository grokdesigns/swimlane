# Overview

The AFS Markdown to PDF Converter transforms Markdown-formatted text into professionally styled PDF documents with the AFS purple theme. This connector is designed to process security reports, case summaries, and other documentation generated by GenAI or manual workflows.

## Prerequisites

No external prerequisites are required. The connector is self-contained with all necessary dependencies and assets (including the AFS logo) built into the container.

## Capabilities

This Connector provides the following capabilities:

* Convert Markdown text to styled PDF documents
* Automatic AFS purple theme styling with branded footer
* Configurable document titles and timestamps
* Base64-encoded PDF output for easy integration with Swimlane workflows

### Limitations

* Maximum input size: 1MB of Markdown text
* Output format: PDF only (Letter size, US standard)
* Requires Markdown-formatted input text

## Asset Setup

This connector does not require any asset configuration. No API keys, credentials, or external connections are needed.

## Tasks Setup

### Process Report Response

**Inputs:**

- `markdown_text` (required): The Markdown-formatted text to convert to PDF
- `document_title` (optional): Title to display in the PDF document header (default: "Security Report")
- `include_timestamp` (optional): Add generation timestamp to the document header (default: true)

**Outputs:**

- `success`: Boolean indicating whether the conversion was successful
- `message`: Status message or error details
- `pdf_content`: The generated PDF document (base64-encoded)

**Example Usage:**
Use this action in a workflow after generating a report with GenAI or compiling case information. The output `pdf_content` can be saved as an attachment or sent via email.

## Notes

* The AFS purple theme and logo are built into the connector
* PDF generation is performed entirely within the container with no external dependencies
* The connector uses WeasyPrint for high-quality PDF rendering
